# RAD145 Interactive Study Center

A browser-based study center for radiography students, covering **Radiographic Physics**, **Radiographic Positioning**, and **Anatomy & Physiology I**.

## Features

- Lesson notes, visual references, and interactive flashcards
- Graded section quizzes and cumulative exams with answer explanations
- Calculation practice and formula references
- Personal flashcards with JSON export and import for sharing
- Study progress, test history, and history/reset controls
- Progress backup and restore
- Correction reports for questions or answers that need review

## Getting Started

Open `index.html` in a modern web browser, or access the site through its GitHub Pages deployment when enabled.

No installation, server, or build step is required. The site uses **HTML, CSS, and vanilla JavaScript**.

## Progress and Sharing

Study history and personal flashcards are stored locally in each user's browser. Progress does not automatically sync across devices or classmates.

Use the built-in export and import tools to back up progress or share personal flashcards. Correction reports can be exported for review; submitted corrections do not automatically change official answers.
